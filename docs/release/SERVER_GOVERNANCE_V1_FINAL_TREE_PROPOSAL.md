# Server Governance v1 Final Tree Proposal

This final RC favors visible activity over empty specialist channels. Runtime
TempVoice rooms are deliberately excluded from the persistent tree.

## Entry
- `👋｜新人報到`: welcome and first action.
- `📜｜社群規則`: stable, read-only rules.
- `📢｜公告`: durable public announcements, including event notices.
- `🧭｜伺服器導覽`: Kuro guide panel and onboarding navigation.
- `✅｜身分組領取`: role selection.

## Community
- `💭｜一般聊天`: the single member social conversation.

## Game Center
- `📢｜組隊招募`: cross-game LFG before a player chooses a specific game.
- `📋｜遊戲提議`: requests for new games.
- `🗃｜遊戲資料庫`: read-only shared game reference.

## Interests
- `💻｜程式開發` (Dev/AI), `📈｜股票投資` (Invest),
  `🎨｜創作分享` (Creator), `🌙｜深夜交流` (Night Crew).

## Support
- `🎫｜開啟客服單`: one public ticket entry; help guidance belongs in the
  ticket flow rather than a second permanent channel.

## Admin
- `server-logs`, `bot-logs`, `mod-tools`, `bot-control`.

## Game Categories
- Full: VALORANT, 英雄聯盟, APEX, Minecraft: chat, LFG, info, create-entry.
- Compact: 聯盟戰棋, 鬥陣特攻2, CS2: combined chat/LFG and create-entry.
- Voice-only: GTFO, R.E.P.O, Project Zomboid: create-entry only.

Totals: 16 categories, 43 persistent channels, 25 game channels. No archive
category or permanent team voice rooms are proposed.
