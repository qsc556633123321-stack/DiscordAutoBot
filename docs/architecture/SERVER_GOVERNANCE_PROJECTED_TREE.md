# Server Governance Projected Tree

The small-community baseline has 17 categories: seven shared areas plus ten
permission-isolated game categories. Game categories remain separate because a
specific game role must not reveal every other game.

Projected persistent channels: 51 (41 text, 10 voice entry). Runtime temporary
voice rooms are not part of this tree.

- Entry: 5 channels; concise onboarding/welcome/rules/guide/role selection.
- Community: 4 channels; general conversation, community chat, LFG, and info.
- Game Center: 4 channels; lobby, LFG, proposals, and database.
- Interests: 4 role-restricted channels in one shared category.
- Events: 3 channels; Support: 2 channels; Admin: 4 channels in one category.
- Games: 4 full, 3 compact, 3 voice-only layouts; 25 persistent game channels,
  average 2.5 per game.

No archive category exists.
