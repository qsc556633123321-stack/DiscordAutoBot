# Server Governance Before / After

The production-shaped fixture includes canonical channels plus a misnamed and
mis-parented Game LFG channel, a duplicate legacy channel, an unknown user
channel, runtime TempVoice, a ticket, and an obsolete managed category.

The projected plan repairs name/parent/permission drift, preserves unknown,
runtime, and ticket resources for manual review/protection, and allows only
evidence-backed managed obsolete resources into `SAFE_DELETE`. The target is
clarity and lower maintenance cost, not maximizing deletion.
