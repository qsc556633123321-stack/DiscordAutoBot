# Guide-specific Discord Mutation Port Result Contract

This is a candidate-only result model.

| Result | Required fields | Meaning |
| --- | --- | --- |
| `EditSuccess` | `kind`, `messageId` | Edit completed; returned ID is the edited message identity |
| `SendSuccess` | `kind`, `messageId` | Send completed; returned ID is generated by Discord |
| `Failure` | `kind`, `failureKind` | Resource lookup or Discord mutation did not complete |

`messageId` is scalar output only. The port must not expose a raw Discord
Message or Error. Persistence success/failure, Roadmap continuation, and user
interaction results remain outside this contract.
