# Community Publication Channel Lookup Characterization Blockers

No runtime migration was attempted. The blockers are: (1) cache/fetch/name fallback and member DM are co-located; (2) no Channel Lookup Port or adapter is approved; (3) the active consumer does not use the existing domain mapper; (4) stale-cache/type/permission behavior is legacy compatibility behavior rather than a validated policy; and (5) Roadmap has no confirmed active lookup reader.

Recommended next action: retain **No Channel Lookup Runtime Integration Slice Approved** until a dedicated proposal approves a narrow boundary and its compatibility contract.
