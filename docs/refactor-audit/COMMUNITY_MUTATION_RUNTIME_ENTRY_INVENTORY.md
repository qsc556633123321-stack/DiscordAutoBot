# Community Mutation Runtime Entry Inventory

This is a runtime inventory, not a proposed API. `Active Runtime` means the current
event/command loader can reach the entry. `Indirect Active Runtime` means the
entry is dispatched through the interaction compatibility router. Entries that
only compute or reply are retained where they share a mutation workflow, but
their final mutation is explicitly recorded as `none`.

## Inventory notes

- `src/modules/commands/aliasRegistry.js` dynamically discovers legacy commands. That
  is the evidence for the command entries above even where no individual static
  import exists.
- Button and modal handlers deliberately retain `fallbackAllowed` imports. Their
  exact active customIds above are therefore routed through the compatibility
  dispatcher rather than a migrated Community application service.
- Voice entries are recorded only to prevent accidental ownership claims by a
  Community slice. Voice behavior is explicitly excluded from this discovery
  completion pass.
- Guide Status remains absent: no active mutation consumer was found, so it is
  not a mutation candidate.
