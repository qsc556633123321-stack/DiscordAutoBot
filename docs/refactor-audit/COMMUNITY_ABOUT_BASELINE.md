# Community About Baseline

## Pre-migration command contract

| Item | Captured contract |
| --- | --- |
| Source path | `src/legacy/commands/community-about.js` |
| Export contract | `{ data, execute }` |
| `data.toJSON()` deploy payload | `{"options":[],"name":"community-about","description":"了解這個社群是做什麼的","type":1}` |
| Command name / description | `/community-about` / `了解這個社群是做什麼的` |
| Options / default permissions | no options / no default permission field |
| Execute input | Discord interaction; it reads only `interaction.guild` |
| Guild-only behavior | No explicit guard. An absent guild fails while resolving `guild.name`, as before. |
| Acknowledgement | no `deferReply`, exactly one `interaction.reply(...)` |
| Reply payload | `{ embeds: [Embed], ephemeral: true }` |
| Embed source | `src/systems/communityConcierge.js#buildAboutEmbed(guild)` |
| Embed contract | Complete payload template below; no footer/components/allowedMentions; timestamp is generated by the existing source helper. |
| Error / logger / fallback | No local try/catch, logger, or fallback reply. Source errors propagate to the existing interaction error path. |
| Data source | Static facts embedded in the existing read-only `buildAboutEmbed` helper plus `guild.name`; no JSON, DB, docs generation, or environment read. |
| Registry / alias | `aliasRegistry` dynamically loads the legacy command; command registry deploys its `data.toJSON()` payload. |

## Baseline validation

- `npm run test:community` did not exist before this slice. It was intentionally not added until real Community About tests were implemented.
- Existing migration, legacy-boundary, architecture, and quality-gate baselines passed before the active route changed.
- No uncommitted changes existed at the start of this slice.
